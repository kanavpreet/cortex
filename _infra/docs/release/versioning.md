# Versioning

Matik uses **semantic versioning**: `vX.Y.Z`

| Segment | When to bump |
|---------|-------------|
| `X` — Major | Breaking changes or significant architecture shifts |
| `Y` — Minor | New features, backwards-compatible |
| `Z` — Patch | Bug fixes, small non-breaking changes |

> For the full versioning specification see: [Semantic Versioning](https://semver.org/)

Releases are created manually via **GitHub Releases** with hand-written release notes describing what changed, any migration steps, and known issues.
